# CodWeb ロードマップ（進捗・タスク管理の正本）

> これは **進捗管理の唯一の正本** です。タスクは ID（例: `M1-A`）で管理し、状態・完了条件・証拠（コミット SHA / テスト件数 / 実測値）を必ず記録・更新します。
>
> **状態の定義**: `未着手` / `調査中` / `実装中` / `ローカル検証済み` / `実環境検証待ち` / `完了` / `保留` / `対象外`
>
> 運用原則:
> 1. 進行中タスクは原則 1 件。複数を同時に進めない。
> 2. タスク ID は再利用しない。中止したタスクは行を消さず「対象外」+ 理由を残す。
> 3. 作業中に見つけた新問題は新タスクとして登録し、現在のタスクへ混ぜない。
> 4. 完了は AI の自己申告ではなく**証拠**で判定する（コミット SHA / テスト件数 / 実測値）。
> 5. 個別タスクの詳細（目的・範囲・禁止事項・完了条件）は `docs/planning/*_PLAN.md` に書く。

---

## 全体方針

CodWeb は「**Call of Duty を Web に移植して Web からでも AAA 級オンライン FPS をモバイル/PC でプレイ**」を目標とする。
- 商用 IP（CoD の名称・アセット・マップ・キャラクター）は**使用しない**。完全オリジナルで「CoD 相当の品質」を目指す。
- 権威サーバー + クライアント予測を基本アーキテクチャに据える。
- 描画は WebGL2（Three.js）で安定優先、WebGPU は段階導入。
- ネットワークは **Colyseus (v0.16+) + WebTransport** ベース。`datagrams`（UDP 相当）で位置・視点・音声、`streams` で射撃・被弾・キルログ・チャット。永続は HTTPS API。非対応環境は WebSocket フォールバック。

**現フェーズ**: 計画・仕様・設計書ファースト（ソースは未配置）。ドキュメント基盤の整備を進めている。
